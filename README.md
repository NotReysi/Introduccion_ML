## Contexto

- **AF 1, AF 2 y AF 3** (Actividades Fundamentales) utilizan el dataset [Stroke Prediction (Kaggle)](https://www.kaggle.com/datasets/fedesoriano/stroke-prediction-dataset).
  - La AF 1 realiza el análisis exploratorio y la limpieza del dataset.
  - La AF 2 y la AF 3 parten del dataset ya limpio en la AF 1.
- **Proyecto final (PIA):** clasificación de gestos (piedra, papel o tijera) con una red neuronal convolucional (CNN), usando el dataset [Rock, Paper, Scissors](https://www.kaggle.com/datasets/drgfreeman/rockpaperscissors).
- Desarrollado en equipo utilizando notebooks de Python (Google Colab / Jupyter) con `pandas`, `numpy`, `matplotlib`, `scikit-learn` y `TensorFlow/Keras`.
